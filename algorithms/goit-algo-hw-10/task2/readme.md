# Завдання 2. Обчислення інтеграла методом Монте-Карло

Обчислено площу під графіком \(f(x) = x^2\) на проміжку від 0 до 2 (сіра зона на графіку).

Аналітично: \(\int_0^2 x^2\, dx = \dfrac{8}{3} \approx 2.666667\).

Функція `quad` дає той самий результат: `2.666667`.

## Порівняння з методом Монте-Карло

```
   Точок |  Монте-Карло |    Похибка
    1000 |     2.608000 |   0.058667
   10000 |     2.714400 |   0.047733
  100000 |     2.659360 |   0.007307
```

## Висновки

1. Метод Монте-Карло дає наближене значення інтеграла. Результати близькі до аналітичного значення `2.666667` і до результату `quad`.

2. `quad` і аналітична формула точніші. Монте-Карло зручний, коли інтеграл важко порахувати формулою: кидаємо випадкові точки в прямокутник і оцінюємо, яка частина з них потрапила під криву.
