# Завдання 1. Алгоритм вирішення задачі про здачу

Маємо набір монет `[50, 25, 10, 5, 2, 1]`. Програма порівнює жадібний алгоритм (`find_coins_greedy`) та алгоритм динамічного програмування (`find_min_coins`) для видачі решти.

Для суми `113` обидві функції повертають той самий набір монет: `{50: 2, 10: 1, 2: 1, 1: 1}`.

## Складність алгоритмів

- Жадібний алгоритм має складність **O(n)**: один цикл по номіналах монет.
- Алгоритм динамічного програмування має складність **O(n²)**: два вкладені цикли (по сумі і по номіналах).

## Порівняння за часом виконання

Виміри зроблені через `timeit` для сум `100`, `1000`, `10000`, `50000` (по 10 повторів).

## Висновки

1. **Жадібний алгоритм** має складність **O(n)** і працює значно швидше. Навіть на великих сумах час майже не змінюється, тому для касового апарата зі стандартними номіналами він зручніший.

2. **Алгоритм динамічного програмування** має складність **O(n²)** і з ростом суми працює помітно повільніше. Зате він завжди знаходить мінімальну кількість монет, навіть якщо жадібний алгоритм дає неоптимальний результат.
